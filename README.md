# Taxi Fare Prediction using Machine Learning

## 📌 Project Overview

Taxi Fare Prediction is a Machine Learning project developed to predict the estimated fare amount of a taxi trip based on trip-related input data.

This project uses an NYC Taxi dataset containing 100,000 records and demonstrates an end-to-end machine learning workflow, including data preprocessing, handling missing values, feature preparation, model training, prediction, and web application integration.

A Flask-based web application is developed to provide a simple and interactive interface for users to enter trip details and obtain a predicted taxi fare.

## 🎯 Project Objectives

- Predict taxi fare amounts using Machine Learning
- Analyze real-world NYC taxi trip data
- Handle missing and inconsistent data
- Perform data preprocessing and feature preparation
- Train a Machine Learning model for fare prediction
- Create a user-friendly prediction interface
- Integrate the trained model with a Flask web application

## 🗂️ Dataset

The project uses an NYC Taxi dataset containing approximately 100,000 records.

The dataset includes information related to taxi trips and fare amounts. The dataset contains missing values, which are handled during the preprocessing stage before model training.

## 🤖 Machine Learning

The project applies Machine Learning techniques to learn the relationship between taxi trip information and the corresponding fare amount.

The trained model is used to generate an estimated taxi fare based on the input provided by the user through the web application.

## 🌐 Flask Web Application

A Flask-based web application is integrated with the Machine Learning model.

The application allows users to enter relevant taxi trip details through a web interface. The entered information is processed by the application and passed to the trained model to generate an estimated taxi fare.
