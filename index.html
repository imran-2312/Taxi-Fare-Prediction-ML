About This Project

This project presents an intelligent fare estimation system for urban taxi services in Chennai, developed as part of an internship in Data Science & Machine Learning. The system leverages four regression-based ML algorithms — Linear Regression, Decision Tree, Random Forest, and Polynomial Regression — to deliver accurate, real-time fare predictions based on route distance and passenger data. Designed to demonstrate the practical application of predictive analytics in smart transportation infrastructure.
